2. Production Calculation Fields (10 Formulations)

To ensure analytical integrity without formula inflation, 10 calculated fields were mathematically audited and specified for native Tableau authoring:

  • Average Anxiety Score: AVG([Anxiety Score]) — Population & subgroup anxiety index (Overall: 52.59).
  • Average Depression Score: AVG([Depression Score]) — Population & subgroup depression index (Overall: 48.09).
  • Average Daily Screen Time: AVG([Daily Screen Time (hrs)]) — Digital saturation benchmark (Overall: 7.10 hrs).
  • Total Student Cohort: COUNTD([User ID]) — Dynamic population count denominator (200).
  • Therapy Active Indicator: IF [Therapy Type] != 'No Therapy' THEN 'Enrolled in Therapy' ELSE 'No Therapy' END.
  • High Stress Indicator: IF [Stress Level] = 'High' THEN 'High Stress' ELSE 'Low or Moderate Stress' END.
  • Psychological Distress Index: ([Anxiety Score] + [Depression Score]) / 2.0 — Combined comorbid symptom score.
  • Age Group: IF [Age] <= 19 THEN '18-19' ELSEIF [Age] <= 21 THEN '20-21' ELSE '22+' END.
  • Active Therapy Progress Score: IF [Therapy Type] != 'No Therapy' THEN [Progress Score] ELSE NULL END.
  • High-Risk Sleep Deficit Flag: IF [Stress Level] = 'High' AND [Sleep Quality] = 'Poor' THEN 'High Risk' ELSE 'Standard Risk' END.

3. Web Integration & Embedding Architecture

The web platform is built using Python Flask, rendering server-side Jinja2 templates and serving responsive Tableau embed containers. The architecture supports:

  • Configurable Cloud Embedding: Environment variables (TABLEAU_DASHBOARD_URL and TABLEAU_STORY_URL) enable zero-code live URL injection as soon as workbooks are published to Tableau Public.
  • Tableau Web Component & JS API v2 Support: Uses modern <tableau-viz> web components with progressive fallbacks.
  • Integrated Prototype Fallbacks: In the absence of live cloud URLs, high-resolution multi-device dashboard prototypes (Desktop 1920×1080, Tablet 1024×768, Mobile) and the 5 sequential story scenes are rendered interactively with zero visual degradation.
